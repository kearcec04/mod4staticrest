Graphics Design is one of the key parts of making a website. Graphics Designers create images, logos, , banners, company mastheads,videos , etc , etc.

Graphic
Frameworks are essentially a set of css rules, set and predefined for you so you don't have to write and entire LOG.css. Take a look at the bootstrap css AND java folders. There are many different frameworks and companies looking for ppl with familiarity in certain ones. They also differ which ones a company will use from Project to Project according to their needs for an overall layout/design. so familiarize with as many of them as you can. Starting with the most popularly currently used ones(demand/popularity changes constantly;e.g. which ones developers use).

Framework
I decided to use a google font .api for this lesson. APIs can be used for a variety of things. This may be the most simple use for an API. It handles the communication between the font docuemnt at google all the way to your IDE or Github Page. You just have to link it in your CSS file and the API will do the rest!
